# Pacote de avaliação — PokeCentral Desktop 0.12.2

Este pacote foi preparado para solicitar autorização da versão gratuita do PokeCentral Desktop. Ele não afirma que o aplicativo já foi aprovado.

## Ordem sugerida para envio

1. Enviar a mensagem curta de apresentação no canal indicado pela staff.
2. Anexar ou disponibilizar o resumo para avaliação.
3. Enviar o vídeo de aproximadamente três minutos.
4. Fornecer o instalador somente pelo canal combinado com a staff.
5. Informar o hash SHA-256 para conferência.
6. Registrar a resposta e todas as condições recebidas.

## Arquivos principais

- `01_MENSAGEM_INICIAL_DISCORD.md`: texto curto pronto para o primeiro contato.
- `02_RESUMO_PARA_AVALIACAO.md`: escopo funcional e perguntas objetivas.
- `03_ROTEIRO_VIDEO_3_MINUTOS.md`: roteiro para gravar uma demonstração clara.
- `04_CHECKLIST_ANTES_DO_ENVIO.md`: itens que ainda dependem de ação humana.
- `05_MANIFESTO_DA_VERSAO.txt`: versão, instalador e hash verificado.
- `DOCUMENTOS`: cópias dos documentos técnicos e de segurança.
- `EVIDENCIAS`: capturas geradas a partir da versão 0.12.2 com dados demonstrativos.
- `EVIDENCIAS_POSTS`: transcrições recebidas e controle dos links oficiais pendentes.
- `VIDEO_DEMONSTRACAO_POKECENTRAL_0.12.2.mp4`: demonstração legendada de 2min46s.
- `ANALISE_MICROSOFT_DEFENDER.txt`: verificação local complementar.

## Instalador

O instalador permanece na pasta `release` do projeto e não foi duplicado neste pacote:

`release/PokeCentral Desktop Setup 0.12.2.exe`

A versão ainda não possui assinatura digital comercial. Isso deve ser informado à staff e aos primeiros testadores.
